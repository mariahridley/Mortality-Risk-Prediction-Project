# Mortality Risk Prediction Project

## Overview
This project explores the use of machine learning techniques to predict mortality risk using large-scale healthcare data. The goal was to identify patterns and factors associated with patient outcomes through data preprocessing, feature analysis, and predictive modeling.

The project demonstrates skills in data cleaning, exploratory data analysis, machine learning, and model evaluation using Python and data science libraries.

---

## Objectives
- Analyze healthcare-related data to identify trends associated with mortality risk
- Preprocess and clean large datasets for machine learning applications
- Train and evaluate predictive models
- Visualize key findings and feature relationships
- Explore how data science can support healthcare decision-making

---

## Dataset
The dataset used in this project contains large-scale healthcare and patient-related information used to analyze mortality risk patterns.
Due to dataset size and/or privacy limitations, the 2 full datasets are not included in this repository.

---

## Project Workflow

### 1. Data Preprocessing
- Removed missing or invalid values
- Cleaned and formatted data for analysis
- Selected relevant features for modeling

### 2. Exploratory Data Analysis
- Examined relationships between variables
- Visualized trends and distributions
- Identified potential predictors of mortality risk

### 3. Machine Learning
- Built predictive models using scikit-learn
- Trained and tested models on processed data
- Evaluated model performance using standard metrics

### 4. Results & Insights
- Most observed correlations were weak, zero, or negative
- Findings suggested that mortality outcomes are influenced by many additional confounding variables not included in the dataset
- The project highlighted the complexity of healthcare prediction problems and the limitations of incomplete real-world datasets
- Demonstrated the importance of careful interpretation when working with predictive healthcare analytics
